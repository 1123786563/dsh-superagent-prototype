## 实施裁决

- 用固定 Git commit 的只读对象工具替代复制整个目标 checkout，减少磁盘复制且排除未提交代码；独立 Session 仍有独立工作目录。目标默认分支新 commit 必须已存在于本地，否则明确失败而不切换到旧版本。
- 状态目录统一派生于同用户的本机根，而非自由配置 stateDir，避免同一仓库在不同 profile 用不同目录绕过锁。
- 对于无法确定是否发出的 POST，优先避免重复 @，仅隔离该张 issue 并保留 publish_uncertain 定期对账；其他独立任务继续。工单的停滞观察只更新状态，不自动停止、重派或向 issue 追加提醒评论。
